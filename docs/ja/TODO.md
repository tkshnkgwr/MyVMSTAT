# 開発ロードマップとタスク管理: TODO

本ドキュメントは、**MyVMSTAT** の現在の実装状況、直近の対応タスク、および将来の拡張提案（バックログ）を管理します。

## 1. 実装済みの機能 (Done)

本プロジェクトにおいて、すでに実装され検証が完了している機能の一覧です。

### 1.1 コア監視機能
- **Linux ネイティブテレメトリの直接取得**:
  - Cライブラリ等を介さず、`/proc/stat` および `/proc/meminfo` を直接パースして、CPU (user/system/idle/iowait)、メモリ (free/buff/cache/swpd)、コンテキストスイッチ数、割り込み数を最小オーバーヘッドで取得。
- **クロスプラットフォーム（非Linux/Windows）サポート**:
  - `sysinfo` クレートを利用した動的なテレメトリ取得へのフォールバック。CPU 全体使用率、物理メモリ、プロセスリストからの稼働状態の検出に対応。
- **dstat 風のビジュアル強調 (ANSIカラーコード)**:
  - 活性度の低い値（0）の灰色化、警告および限界値に対する黄色・赤色太字での強調、絶対時間タイムスタンプの青色表示。

### 1.2 CLIおよびプロセス制御
- **堅牢なコマンドライン引数解析**:
  - 監視間隔（`delay` 秒数、小数対応）およびサンプリング回数（`count`）の制御。
  - ヘルプ表示（`-h`, `--help`）、バージョン表示（`-v`, `--version`）オプション対応。
  - パースエラーや過剰引数に対する適切な Usage 出力とエラーハンドリング。
- **Windows Named Mutex による二重起動の防止**:
  - `common_lib` から提供される名前付きミューテックスを使用した、多重起動の抑止と即時異常終了処理。
- **Cargo Features による機能・依存関係の分離**:
  - `sysinfo` および `windows_desktop` feature を導入し、依存関係のオプショナル化およびモジュール切り替えを実現。


### 1.3 CI/CD・開発環境
- **GitHub Actions を用いたリリース自動化**:
  - メインブランチへのプッシュを契機とする、バージョン自動バンプおよび Git タグ自動生成・プッシュ。
  - クロスコンパイルによる Windows / Linux 向けリリースアセットの自動パッケージングと GitHub Release への自動アップロード。
- **最適化されたリリースプロファイル**:
  - バイナリサイズ削減（`opt-level = 'z'`, `strip = true`, `lto = true`）による、約201KBの軽量バイナリの実現。

## 2. 直近のタスク (In Progress / Todo)

実装の継続性および動作検証から導き出された、現在進行中または直近で着手すべきタスクです。

### 2.1 機能拡張・メトリクス補完
- `[ ]` **Windows 環境における不足メトリクスの取得拡張**:
  - **現状**: Windows（非Linux）環境では `cs`, `in`, `buff`, `cache`, `sy`, `wa` が `0` (灰色) のまま固定されています。
  - **対応**: Windows API（パフォーマンスカウンタやシステム情報APIなど）を直接叩くか、適した軽量ライブラリを導入し、コンテキストスイッチ数や割り込み数、メモリ詳細（バッファ・キャッシュに相当するシステムキャッシュ領域など）を取得できないか調査・実装します。
- `[ ]` **Linux 極小環境（コンテナ等）でのフォールバック動作の検証**:
  - **現状**: `/proc` が制限されている、または一部しかマウントされていない極小 Linux コンテナ環境での挙動が未検証です。
  - **対応**: `/proc` ファイルの読み込みに失敗した際、安全にエラーを出して終了するか、`sysinfo` 側へフォールバックするロジックのロバストネスを強化します。

### 2.2 テスト・品質向上
- `[ ]` **Windows環境での pwsh 文字コード検証の強化**:
  - Windows 端末（特に日本語環境の PowerShell 5.1 / 7）での `cargo run` 時の ANSI カラー表示および文字化け挙動をさらにテストします。

## 3. 将来的な拡張機能の提案 (Backlog)

製品のユーティリティ性を高めるための、中長期的な機能改善提案です。

- **出力形式の切り替えオプション (`--format`)**:
  - 標準の vmstat テーブル出力だけでなく、他ツール（Datadog や自作監視スクリプト）との連携用に、CSV や JSON 形式で構造化データを出力するモードを追加する。
- **ファイルロギング機能 (`--output <file_path>`)**:
  - 画面上にリアルタイム表示を行いながら、同時にタイムスタンプ付きデータを指定のテキストファイルに書き出すロギング機能の追加。
- **インタラクティブキー入力を受け付ける機能**:
  - ループ実行中にキー入力を監視し、例えば `Space` キーでヘッダー（プロット項目名）を再描画したり、`q` キーで安全にループを終了させる機能。
