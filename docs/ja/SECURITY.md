# セキュリティポリシー: SECURITY

本ドキュメントは、**MyVMSTAT** におけるセキュリティ方針、サポート対象バージョン、および脆弱性が見つかった場合の報告手順について定義します。

---

## 1. サポート対象バージョン

以下のバージョンに対して、セキュリティアップデートを提供します。

| バージョン | サポート状況 |
| :--- | :--- |
| **v1.3.x** | 🟢 サポート対象 (最新リリース) |
| **< v1.3.0** | 🔴 サポート終了 |

脆弱性やセキュリティ上の問題が発見された場合は、原則として最新のマイナー/パッチバージョンに対して修正プログラムをリリースします。旧バージョンを使用しているユーザーは、速やかに最新バージョンへアップデートすることを推奨します。

---

## 2. 脆弱性の報告手順

本ツールにおけるセキュリティの脆弱性を発見した場合は、GitHub Issue などの公開掲示板には書き込まず、以下の手順でプライベートに報告してください。

1. **報告方法**:
   リポジトリ管理者または公開されている連絡先へプライベートにメール等を送信してください。
2. **記載いただきたい情報**:
   - 脆弱性の詳細と影響範囲
   - 再現手順（概念実証（PoC）コードや使用したコマンド引数）
   - 想定されるリスク（クラッシュ、リソース枯渇など）
3. **開示について**:
   報告を受理した後、管理者が脆弱性を検証し、修正パッチをリリースします。修正が適用されリリースが完了するまでは、情報の一般公開（開示）をお控えください。
